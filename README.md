# ransomware-python
Projeto de ransomware em Python

## sobre 
Este projeto mostra como criptografar e recuperar um arquivo usando Python

## Arquivo
-encrypter.py: criptografa o arquivo.
-decrypter.py: restaura o arquivo.

## Objetivo
Aprender sobre criptografia usando Python
